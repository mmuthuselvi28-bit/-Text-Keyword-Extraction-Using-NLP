Text Keyword Extraction Using NLP
Author: Muthuselvi M 

Project Description
Text Keyword Extraction Using NLP is a simple application that identifies the important keywords from a given paragraph. The application removes common words and punctuation, counts the frequency of words, and displays the most frequently used keywords.

Objective
The main objective of this project is to extract important keywords from text using basic Natural Language Processing (NLP) techniques.

Technologies Used
Python
Natural Language Processing (NLP)
Google Colab
Regular Expressions
Features
Accepts a paragraph as input
Removes punctuation
Removes common/stop words
Counts keyword frequency
Displays the top keywords
Fast execution
No external dataset required
How It Works
User enters paragraph
        ↓
Convert text to lowercase
        ↓
Remove punctuation
        ↓
Remove common words
        ↓
Count keyword frequency
        ↓
Display top keywords

Example
Input:

Python is a popular programming language.
Python is easy to learn and Python is useful for machine learning.

Output:

Keywords:

python : 3 time(s)
popular : 1 time(s)
programming : 1 time(s)
language : 1 time(s)
easy : 1 time(s)
learn : 1 time(s)
useful : 1 time(s)
machine : 1 time(s)
learning : 1 time(s)

Conclusion
